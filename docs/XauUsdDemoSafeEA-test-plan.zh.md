# 测试计划

这里区分三层。只有前两层在这次交付里执行了。第三层必须由你在自己的 MT5 里做。

## 1. 已经跑过的规则模型

在仓库根目录执行：

```text
python3 -m unittest discover -s tests -v
```

`tests/xau_demo_model.py` 是一份离线规则，不是 MQL5。美元例子使用“1.00 手每 1 美元价格波动等于 100 美元”的假公式，只为检查加减，不是行情。

模型检查这些决定：

- 挂上之前的 K 线不产生信号。
- 多头和空头的回踩、收盘突破、影线不算突破。
- 趋势翻转的那根 K 线只作废，不立刻反向建仓。
- 24 根后的下一根作废。
- 错过下一根进场窗口、进场 K 线已走过 2 分钟，都不再下单。
- 缺口超过 48 根就丢弃未完成形态。
- 有持仓时不建立新形态。
- 同一根 K 线只允许一次发送标记。
- 止损对齐和经纪商最小距离只会把止损放远。
- 风险 = 止损亏损 + 手续费缓冲 + 滑点额外亏损，点差不再加一次。
- 0.01 手必须符合最小手数、步长、上限和持仓量限制。
- 浮动盈利不能抵消已实现亏损。新的一天只解除当日金额停止。
- 空账户可以启动。手工单、相同魔法号但没有记录票号的单，都拒绝认领。
- 只有刚确认的新票号才允许平仓。

## 2. 已经跑过的源码静态检查

`tests/test_xau_demo_source.py` 检查：

- 新 EA 是单文件，没有 `#include`。
- 源码括号数量平衡。这不能代替编译器。
- 含有 `OrderCalcProfit`、对冲判断、模拟账户判断、H1、EMA20/50、ATR14、冻结距离、手数上限和固定 0.01。
- 不含联网、DLL、改止损、对冲平仓这些调用。
- 原来的 EA、头文件、LICENSE、README 的 SHA-256 没有变化。

## 3. 你自己的 MT5 检查

下面每一项都还没有在这里执行。

1. MetaEditor 打开 `XauUsdDemoSafeEA.mq5`，按 F7。0 错误、0 警告才算编译通过。把结果记在你自己的笔记里，不要把没有编译写成“已编译”。
2. 用空的美元对冲模拟账户，把 EA 挂到 XAUUSD 的 H1 图上。日志应出现“初始化完成”。
3. 把同一文件挂到真实账户图表上。日志应出现“拒绝启动”，并且账户里没有新单。
4. 在已经有手工黄金单的模拟账户上挂载。日志应出现“拒绝启动”，手工单的手数、止损、止盈都不变。
5. 策略测试使用说明里的设置。看日志里的跳过原因是否包含报价、止损、止盈和风险数字。不要把测试器曲线当成收益承诺。
6. 如果想检查连亏停止，只能在测试器或空模拟账户里观察，不要在有旧仓的账户上做。

任何一步和日志不符，就不要继续使用。先保留日志，再改代码。
